# 華語每日即時新聞與語法練習平台 (TOCFL A2-B1)

本專案為針對外籍生華語學習所設計的互動式學習網頁，提供每日自動更新的新聞閱讀、重點語法解析、心智圖生詞以及課後問答練習。

---

## 🔗 網站連結
👉 **[點此前往華語學習網頁平台](https://baoyuank-sudo.github.io/mandarin-news/)**  
*(註：請將上方的網址替換為您實際開啟 GitHub Pages 後取得的網址)*

---

## ✨ 網頁特色功能

1. **📰 每日新聞輪播**：每天自動轉換不同主題（如觀光、綠能科技、節慶文化），並附有雙語對照與字數統計。
2. **🔊 專屬語音朗讀**：
   - 支援 0.8x 慢速純中文朗讀新聞短文。
   - 點擊生詞可發音，並提供「生詞用法詳細解說」語音。
3. **💡 實用語法與生詞**：精選 2 個核心句型與 10 個 TOCFL A2-B1 級重點生詞。
4. **✍️ 互動問答**：提供 3 題課後練習，支援語音播放題目。

---

## 🎯 適合對象
- 準備 **華語文能力測驗 (TOCFL) A2-B1** 級別的外籍學生。
- 華語教師用於課堂輔助教材或課後補充練習。

---

## 🛠️ 技術說明
- 本網頁採用 **HTML5 / CSS3 / JavaScript** 獨立開發。
- 語音功能基於瀏覽器內建 **Web Speech API (zh-TW)** 技術。
- 無需安裝額外外掛，支援手機與電腦端開啟。
